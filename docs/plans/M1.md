  worktree", while its deny reason and D-045 speak of the reviewer's *own* worktree. As written, a
  reviewer could also edit another linked worktree of the same repository, such as an implementer's
  under `.claude/worktrees/`. Options: (a) keep the rule as written, any linked worktree (T1 builds
  this); (b) change GUARD-001 to only the linked worktree that contains the reviewer's `cwd`, which
  would need a spec change before T1 or a follow-up rule.
